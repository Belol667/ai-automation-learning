# День 1 — мой конспект

## Основные термины
1. Repository (репозиторий) — место для хранения файлов проекта и истории изменений.

2. Commit (коммит) — зафиксированная версия изменений проекта.

3. Git — программа для отслеживания изменений в файлах и сохранения истории проекта.

4. GitHub — онлайн-платформа для хранения Git-репозиториев и совместной работы над проектами.

5. README — файл с описанием проекта и инструкциями для тех, кто его открывает.
